## Perfil profesional

Soy **Riutexu**, desarrollador **Full Stack autodidacta** desde 2024. Construyo productos completos de forma autónoma: desde la interfaz hasta la base de datos y el despliegue. Mi trabajo se concentra en tres áreas:

| Área | Tecnologías | Qué resuelve |
|---|---|---|
| 🌐 **Aplicaciones web seguras** | PHP 8.3 · JavaScript · MariaDB | Sistemas de gestión con mitigación del OWASP Top 10 (Argon2ID para contraseñas, CSRF, rate limiting) |
| ⚙️ **Automatización de sistemas** | PowerShell 7 · Batch · Linux | Herramientas de optimización, privacidad y seguridad para Windows |
| 📱 **Apps Android nativas** | Kotlin · Jetpack Compose · Media3 | Aplicaciones 100% locales, sin cuentas ni telemetría |

**Principios de trabajo:** seguridad por diseño · código legible y mantenible · optimización medible.

## Arquitectura

### Web (Kike Surveyor)

```
+------------------+      +------------------+      +------------------+
|   🌐 Web App     +----->+   🔌 API REST   +----->+   🗄️ MariaDB     |
|   PHP + JS       |      |   PHP + JSON     |      |   InnoDB         |
+------------------+      +------------------+      +------------------+
        |                        |                        |
        +------------------------+------------------------+
                                |
       +----------------------------------------------------------+
       |          🔐 CAPA DE SEGURIDAD · Argon2ID | CSRF |        |
       |      Rate Limiting | Session FP | HSTS · CSP · XFO       |
       +----------------------------------------------------------+
```

### Android (Ryutify)

```
+------------------+      +------------------+      +------------------+
|   🎧 Android     +----->+   🔌 API Cifrada +----->+   🗄️ BD Local     |
|   App Nativa     |  E2E |   AES-256 + JWT  |      |   SQLite         |
|   Kotlin         |      |                  |      |   Offline-first  |
+------------------+      +------------------+      +------------------+
                                |
       +----------------------------------------------------------+
       |     🔒 Cifrado extremo a extremo · Sincronización local   |
       +----------------------------------------------------------+
```
